金鑰與簽章

公鑰只能驗證：支援 SPKI（BEGIN PUBLIC KEY）、PKCS#1（BEGIN RSA PUBLIC KEY）、X.509 憑證、JWK、JWKS。私鑰可以簽章：支援 PKCS#8、PKCS#1（BEGIN RSA PRIVATE KEY）、SEC1（BEGIN EC PRIVATE KEY）、JWK。

    這個頁面的 Content-Security-Policy（在原始碼最上方）讓瀏覽器拒絕載入任何外部檔案，也拒絕連到 www.googleapis.com 以外的位址，所以 token 和私鑰都送不出去。想要再保險一點，可以先斷網再開啟，然後手動貼上公鑰。頁面不使用 localStorage 或 cookie，關掉分頁就什麼都不留。即使如此，也請只在這裡使用測試用的私鑰，不要貼正式環境的私鑰。
